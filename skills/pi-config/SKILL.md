# Changing pi's configuration

Everything under `~/.pi/agent` is generated by Nix and read-only. `pi install`, `pi config`, Ctrl+S in `/model` and `/settings` changes do not persist. Make every change in `~/nixos` instead.

## Where things live
All in `~/nixos/modules/apps/ai/pi/`:
- `default.nix`: settings.json, keybindings.json, permission rules, plan-mode config, the `pi` wrapper, the Ctrl+G editor script, and which files are linked into `~/.pi/agent`.
- `_pkg/default.nix`: the pi package (version, tarball hash, `npmDepsHash`). Lockfile: `_pkg/package-lock.json`.
- `_pkg/extensions.nix`: pinned extensions (name, version, hash, `npmDepsHash`). Each has `_pkg/extensions/<dir>/package.json` and `package-lock.json`.
- `_files/onedark.json`: the theme. `_files/agents/*.md`: subagents. `_files/skills/*/SKILL.md`: skills. `_files/AGENTS.md`: global instructions.

## Adding or updating an extension
1. Download the npm tarball for the exact version and read its README for config and conflicts.
2. Create `_pkg/extensions/<dir>/package.json` from the package's own, with `devDependencies`, `scripts` and `peerDependencies` removed, and with any non-host peer dependencies moved into `dependencies`. Host packages (`@earendil-works/*`, `typebox`) must not be in `dependencies`.
3. Generate the lockfile next to it: `npm install --package-lock-only --ignore-scripts --omit=dev --legacy-peer-deps`.
4. Add it to `sources` in `extensions.nix` (prefetch the tarball hash with `nix-prefetch-url`). Set its `npmDepsHash` to `null` if it has no dependencies; otherwise use a fake hash, build, and copy the real one from the error.
5. `git add` the new files.

## Settings
Edit the attribute sets in `default.nix` (they become JSON). Keys follow pi's docs in the installed package (`docs/settings.md`, `docs/keybindings.md`).

## Verify, then hand over
Follow the `nix` agent's verification steps: build the desktop configuration, read the generated files, and test pi with them (`pi --version`, `pi list`, a `-p` run). Never run `sudo` or rebuild yourself; tell the user to run `sudo nixos-rebuild switch --flake ~/nixos#personal-desktop` and restart pi.
