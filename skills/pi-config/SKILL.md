# Changing pi's configuration

Everything under `~/.pi/agent` except `npm/` and `sessions/` is generated by Nix and read-only. `pi install`, `pi config`, Ctrl+S in `/model` and `/settings` changes do not persist. Make changes in the two repos below instead.

## Where things live
- `~/setup/pi-config/module.nix` (the flake input `pi-config`): `programs.pi-coding-agent` (settings.json, keybindings.json, package list), the permission rules, plan-mode config, the `pi` wrapper and `pi-assistant`.
- `~/setup/pi-config/files/`: the theme (`onedark.json`) and the startup header extension.
- `~/setup/nixos/modules/apps/ai/pi/default.nix`: desktop glue (niri binds, zsh aliases, logo).
- `~/setup/agent-markdown-files` (input `pi-config/agent-markdown-files`): `AGENTS.md`, `assistant.md`, `agents/*.md` (subagents), `skills/*/SKILL.md`.
- pi itself comes from the `llm-agents` flake input (numtide/llm-agents.nix).

## Common changes
- Add a package: append `"npm:<name>@<exact version>"` to `settings.packages`. Read its README for config files and conflicts first. pi installs it into `~/.pi/agent/npm/` on the next start.
- Update pi: `nix flake update pi-config/llm-agents` in `~/setup/nixos`.
- Change a markdown file: edit it in `agent-markdown-files`, commit and push, then `nix flake update pi-config/agent-markdown-files` in `~/setup/nixos`. For `pi-config` itself: push, then `nix flake update pi-config`. Never commit or push without asking the user.
- Settings keys: see `docs/settings.md` and `docs/keybindings.md` in the installed pi package.

## Verify, then hand over
Follow the `nix` agent's verification steps (build, read the generated files, test pi with them). Never run `sudo` or rebuild yourself; tell the user to run `sudo nixos-rebuild switch --flake ~/setup/nixos#personal-desktop` and restart pi.
