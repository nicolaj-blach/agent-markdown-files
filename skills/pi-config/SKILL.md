# Changing pi's configuration

Everything under `~/.pi/agent` except `npm/` and `sessions/` is generated by Nix and read-only. `pi install`, `pi config`, Ctrl+S in `/model` and `/settings` changes do not persist. Make changes in the two repos below instead.

## Where things live
- `~/nixos/modules/apps/ai/pi/default.nix`: `programs.pi-coding-agent` (settings.json, keybindings.json, package list), the permission rules, plan-mode config, the `pi` wrapper and the Ctrl+G editor script.
- `~/nixos/modules/apps/ai/pi/_files/onedark.json`: the theme.
- `~/projects/personal/agent-markdown-files` (the flake input `agent-markdown-files`): `AGENTS.md`, `agents/*.md` (subagents), `skills/*/SKILL.md`.
- pi itself comes from the `llm-agents` flake input (numtide/llm-agents.nix).

## Common changes
- Add a package: append `"npm:<name>@<exact version>"` to `settings.packages`. Read its README for config files and conflicts first. pi installs it into `~/.pi/agent/npm/` on the next start.
- Update pi: `nix flake update llm-agents`.
- Change a markdown file: edit it in `agent-markdown-files`, commit and push, then `nix flake update agent-markdown-files` in `~/nixos`. Never commit or push without asking the user.
- Settings keys: see `docs/settings.md` and `docs/keybindings.md` in the installed pi package.

## Verify, then hand over
Follow the `nix` agent's verification steps (build, read the generated files, test pi with them). Never run `sudo` or rebuild yourself; tell the user to run `sudo nixos-rebuild switch --flake ~/nixos#personal-desktop` and restart pi.
